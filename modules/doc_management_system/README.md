# 📄 SGC Automated Document & Flowchart Generator

## Overview
An enterprise engine designed to automate Quality Management Systems (SGC). Takes structured data or natural language descriptions and generates ISO-compliant corporate manuals (`.docx`) and visual process flowcharts (`.drawio` & `.svg`).

## Key Features
- **Draw.io XML Generator:** Constructs structured flowchart diagrams programmatically.
- **SVG Rendering Engine:** Exports high-resolution vector diagrams.
- **Docx Templating:** Generates standardized corporate procedure manuals.

## Setup & Environment
1. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
2. Run generator script:
   ```bash
   python src/ai_engine.py
   ```

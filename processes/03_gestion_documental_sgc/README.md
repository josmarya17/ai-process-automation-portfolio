## 🇪🇸 Español

### Descripción del Proceso
Proceso automatizado para Sistemas de Gestión de Calidad (SGC). Transforma notas de procesos y matrices de responsabilidades en manuales normativos en Microsoft Word (`.docx`) y diagramas de flujo editables en Draw.io (`.drawio` / `.svg`).

### Componentes Clave
- **Generador Draw.io XML:** Construcción programática de diagramas de flujo visuales.
- **Renderizador SVG:** Exportación de gráficos vectoriales de alta resolución.
- **Motor Docx:** Generación de manuales de procedimientos según plantilla ISO.

### Guía de Inicio Rápido
1. Instala dependencias:
   ```bash
   pip install -r requirements.txt
   ```
2. Ejecuta el generador principal:
   ```bash
   python src/ai_engine.py
   ```

## 🇬🇧 English

### Process Overview
An automated process for Quality Management Systems (SGC). Converts process matrices and notes into standardized ISO `.docx` procedural manuals and editable `.drawio` / `.svg` visual flowcharts.

### Key Components
- **Draw.io XML Generator:** Programmatic flowchart architecture generation.
- **SVG Render Engine:** Exports high-resolution vector diagrams.
- **Docx Manual Engine:** Generates standardized corporate procedural documentation.

### Quick Start
1. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the main generator:
   ```bash
   python src/ai_engine.py
   ```

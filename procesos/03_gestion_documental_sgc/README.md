# 📄 Proceso 03: Generador de Documentación SGC y Diagramas de Flujo

## Descripción del Proceso
Proceso automatizado para Sistemas de Gestión de Calidad (SGC). Transforma notas de procesos y matrices de responsabilidades en manuales normativos en Microsoft Word (`.docx`) y diagramas de flujo editables en Draw.io (`.drawio` / `.svg`).

## Estructura de Carpetas
- `codigo_fuente/`: Scripts de procesamiento, generador de Draw.io, SVG y docx.
- `plantillas/`: Plantillas normativas y de procedimientos corporativos.
- `organigrama/`: Generador de diagramas organizacionales.

## Guía de Inicio Rápido
1. Instala dependencias:
   ```bash
   pip install -r requirements.txt
   ```
2. Ejecuta el generador principal:
   ```bash
   python codigo_fuente/ai_engine.py
   ```
